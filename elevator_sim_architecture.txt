What to use for underlying communication layer?

For a real spacecraft, all telemetry and commanding has to take place over radio communication packets...

ROS2 -> underlying communications layer
julia -> solve dynamic equations, turn crank (spin) to find next state via dynamic equations and ODE solver
python -> wrapper / link from ROS2 to julia
??? -> web dashboard / viewer
??? -> user control interface gui
mujoco mojo -> dynamics solver alternate (to julia)
python -> motion plan generator (trapezoid motion plan)
javascript / html -> control panel


foxglove: web-based visualization
vizanti: web visualizer
miti: 3d visualizer
RViz2: ROS2 native visualizer
