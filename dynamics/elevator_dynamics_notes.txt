Simplest dyanmic model:
model evelator as a point mass along a single axis: z

z_dot = sum(Fz) / m_elevator
sum(Fz) = F_motor + F_resistance

Controller (Trajectory Tracking):
- PID Controller
- Sliding Mode Controller (SMC)
- Feed-forward w/ SMC error correction
- Computed Effort Control Method (Computed Torque Method)

F_computed = z_dot_des * m_elevator - F_resistance
F_motor = F_computed
